# Social Network

یک شبکه اجتماعی ساده و کامل با Django که کاربران می‌توانند ثبت‌نام کنند، پست بگذارند، یکدیگر را فالو کنند و تعامل داشته باشند.

---

## ✨ ویژگی‌ها

- ثبت‌نام و ورود کاربران (با ایمیل)
- سیستم فراموشی رمز عبور
- ایجاد، ویرایش و حذف پست
- کامنت و ریپلای (سیستم دو سطحی)
- لایک پست
- فالو و آنفالو کاربران
- پروفایل کاربری (سن، بیو، ایمیل)
- جستجوی پست‌ها
- صفحه شخصی هر کاربر

---

## 🛠️ تکنولوژی‌ها

- **Backend**: Django 6.0.7
- **Database**: PostgreSQL 
- **Frontend**: HTML, Bootstrap 5
- **Authentication**: Custom Email Backend + Django Auth
- **Containerization**: Docker & Docker Compose
- **Other**: Class-Based Views, Signals
